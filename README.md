# Otter.ly 🦦

### Otterly Stay Connected with Others

Otter.ly is a campus-based social media mobile application designed for Universitas Tarumanagara students.

The application aims to connect students, provide campus information, promote student organizations, and support interaction among the university community.

## Project Information

- **Application Name:** Otter.ly
- **Platform:** Android / iOS
- **Framework:** Flutter
- **Programming Language:** Dart
- **Development Environment:** Visual Studio Code
- **Version Control:** Git & GitHub
- **Target Users:** Universitas Tarumanagara Students

## Main Features

- Authentication (Login & Register)
- Home and News Feed
- Create and Manage Posts
- Like and Comment
- Friends and Connections
- User Profile
- Search and Discovery
- Campus Events
- Organization Directory
- Notifications
- Application Settings

## Technology

- Flutter
- Dart
- Shared Preferences
- Local Storage
- GitHub
